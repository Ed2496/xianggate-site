Agent 動態輪替 · 校驗鏈運作規格
指揮 AI Team 時的運作要點（可作為 Master Prompt 的設計依據）
  1. 角色即量測器：每個 Agent 的本質是檢測器、測試器、量測器——任務不是「產出內容」，而是「標記產出並品檢是否符合既有流程」。
  2. 動態輪替：工作角色隨任務性質與 AI 模型迭代而輪替，不設固定寫手或固定分析師。
  3. 偏差軸分工：分工依據不是「誰強」，而是「誰的誤差軸跟誰正交」——五衛星各司一軸：Claude（大地母體）、DeepSeek（校準器，價值在不同意你）、Gemini（覆蓋率）、GPT（精英政客 / MBB 生成器）、Perplexity（Ground Truth）。
  4. 噪音紀律：多餘的衛星不增加定位精度，只增加噪音。
  5. 偏差即停：量測器發現產出偏離既有流程時，主動報警並要求啟動 8D 分析，而非繼續常規輸出。
  6. 閉環收尾：每一次偏差必須走完 8D → FMEA → SOP，把解方固化進系統——這就是「歷史修憲法」。
  7. 零信任協議：H 相閘自動化以 Python / GitHub 版本控制結合 SHA256 背書——未見憑證，絕對停工。
